# GS Shift Log Regression V13 R3 검토

## 중단 원인

제공된 Windows R2 실행 기록은 전체 1,902건 중 1,899건 통과, 3건 실패, 건너뜀 0건입니다. 마지막 STOP으로 후속 반영 단계가 중단됐습니다. 세 실패는 모두 `OIS_AGENT_POLL_INTERVAL = 1000`이라는 정적 검사에서 발생했고, 기록에 출력된 로컬 Agent 값은 `10000`입니다.

`docs/review-2026-09-24.md`의 A03과 바로 아래 보존 목록에는 기존 로컬 유휴 확인 간격 10초를 유지했다는 기록이 있습니다. 10초 변경의 원래 동기는 확정하지 않았습니다. R3는 이 보존 기준과 충돌한 검사를 수정하며 Agent 실행 파일이나 운영 주기를 변경하지 않습니다.

## 수정 기준

- 저장소의 1초 기본값과 검토 기록에 있는 10초 로컬 값을 구분해 지원합니다. 임의의 수치나 잘못된 선언을 무조건 통과시키지 않습니다.
- 유휴 주기는 요청이 없을 때 대기하는 값입니다. 화면 상태 조회의 1초 간격 및 Blower 요청 묶음의 400ms 대기와 구분합니다. 각 기능의 검사는 유지합니다.
- 실제 Agent 코드에서 유휴 대기와 오류 재시도 동작을 추출해 모형으로 검증합니다. 검사가 Agent 실행, Excel 열기, DataPARC 조회를 시작하지 않도록 의존성을 대체합니다.
- R1/R2의 저장 결과 복원, 직접 입력 보존, 선택일 초기화 범위 및 원자적 삭제 수정은 그대로 포함합니다.
- 기존 Multi-NativeOM 검사 100개 assertion 보존 및 알 수 없는 수정에 대한 설치 중단 조건을 유지합니다.

## 최신 화면과 기존 변경 보존

검토 기준 원격 main은 `93f875aeb84be2cf9090a141e6b31290a48adbce`입니다. `6904dc6` 이후 발열량 이력의 표시와 배치가 바뀌었습니다. 해당 UI 변경 5개 파일은 패치 대상이 아니며, `index.html`에서는 혼소율 기간 UI 스크립트의 기존 캐시 URL 한 곳만 변경합니다.

`ois-login.js`, Daily DATA PowerShell 및 그 밖의 비대상 파일을 덮어쓰거나 커밋하지 않습니다. 기존 staged/working 변경을 유지하고, 검토된 파일만 별도 Git index로 커밋합니다. 적용 또는 전체 검사 실패 시 커밋/푸시 단계로 진행하지 않습니다.

## 검증 결과의 범위

상세 실행 결과는 패키지의 `VERIFICATION.json`과 `evidence/`에 기록합니다. 1초 기본값과 10초 로컬 값은 각각 별도 모형에서 검증합니다. 현재 사용자 Agent 전체 바이트와 운영 프로세스를 이 환경에서 직접 읽은 것은 아닙니다.

Linux의 Node 24 및 PowerShell 7 검증 결과와 사용자가 제공한 Windows 실행 결과를 구분합니다. 실제 Windows Excel/COM/DataPARC 조회, 운영 데이터베이스 작업, Agent 재시작 또는 Cloudflare 배포는 수행하지 않았습니다.
