## 실제 제품 수정

1. 혼소율 자동 계산의 미저장 상태와 사용자의 직접 수정 여부를 분리했다. 새 조회가 실패한 뒤 화면을 다시 열면 마지막 정상 결과의 범위를 복원하고, 직접 수정 중인 값은 보존한다.
2. 기존 오전회의 선택일 초기화에서 전역 요청 만료 처리를 제거했다. 선택일의 대상 요청만 정리한다.
3. 확인 후 삭제 API는 버전·진행 중 조회를 D1 batch 내부에서 재확인하고 삭제와 초기화 상태 갱신을 함께 처리한다. 중간 실패·버전 충돌 시 기존 자료를 보존한다.

원래 V13에서 수정한 제품 파일 3개와 로더 URL 1곳은 R1에서도 동일하다.

## R1 추가 변경

V13 작성 뒤 적용된 `29f25c7`의 Solid Fuel 안정화로 CSS 캐시 버전이 바뀌었다.
`solid-fuel-silo-reference-align-v1.test.cjs`가 과거 날짜 문자열만 요구해 최신 코드에서 실패 1개가 추가되었다.
CSS의 기존 정렬 규칙 검사는 유지하고, HTML이 실제 존재하는 CSS를 stylesheet로 정확히 한 번 로드하며 비어 있지 않은 캐시 버전을 사용하는지 검사하도록 바꿨다.
화면 디자인과 CSS 제품 코드는 변경하지 않았다.

## 적용 및 확인 범위

패키지는 57개 대상을 사전 검사하고 백업한다. 이 중 11개는 현재 검사와 통합된 과거 검사 파일이다.
기존 staged/working 변경은 보존하며 검토한 내용과 충돌하는 대상은 덮어쓰지 않고 중단한다.
설치 및 로컬 검사만으로 운영 화면이 바뀌지는 않는다. 반영 명령은 전체 검사 통과 후 검토한 변경만 커밋·푸시한다.
배포는 해당 커밋의 Cloudflare Deployments 성공 여부로 확인해야 한다.

실제 Windows PowerShell 5.1, 회사 PC의 Excel/DataPARC 조회, 운영 DB/Cloudflare 배포는 이번 환경에서 실행하지 않았다.
이전 V13의 실제 Chromium DOM 4개 흐름 검증은 과거 기록으로 보존하며, 이번 R1에서 새로 실행한 검증과 구분한다.
